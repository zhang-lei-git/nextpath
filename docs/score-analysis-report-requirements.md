# 成绩分析与报告闭环

## 目标

家长在初三阶段最多录入 7 次周考、月考或模考。每次确认后，系统自动完成一次可追溯的升学位置分析，并发布一份可回看的 HTML 报告；更正成绩时不覆盖旧报告，而是新增修订快照。

## 可验证需求

| 编号 | 需求 | 验收标准 |
| --- | --- | --- |
| R1 | 成绩可维护 | 可查看全部成绩，进入单条修改页后保存更正。 |
| R2 | 自动分析 | 档案完整时，每次新建或修改成绩自动生成一条分析运行。 |
| R3 | 报告可回看 | 每次运行保存 HTML、输入快照、模型版本、数据版本和生成时间。 |
| R4 | 不覆盖历史 | 修改一条成绩后新增报告，不修改既有报告内容。 |
| R5 | 中考前数据边界清楚 | 分析只读取考试日期之前的已发布历史数据；当年一分一段表、当年录取线和出分后网传数据不得进入中考前报告。 |
| R6 | 体育口径正确 | 模考学科总分默认不含体育 60 分；体育未录入时统一按 60 分计算，录入后直接按录入分数计算。 |
| R7 | 7 次闭环 | 连续录入 7 次模考后产生至少 7 份报告；任一次修订产生新增报告。 |
| R8 | 双口径可比较 | 每次结果保存当前现状与合理预测两套中考计分总分、位置和目标差距；家长页面按目标、当前现状、合理预测顺序呈现。 |
| R9 | 分数位次成对展示 | 每个情景的分数范围与位次范围来自同一预测结果并通过一致性校验。 |
| R10 | 信息分层 | 小程序只展示目标、现状、预测、差距和关键行动；HTML 报告补充趋势、学校梯队、风险和家长可理解的预测理由。 |

## 数据与分析规则

- 预测执行时点等于考试日期。数据版本的参考年份必须早于该考试年份；当年一分一段、录取结果和事后预估一律排除。
- 体育未出分时，录入的是学科总分。系统固定补足体育 60 分再做位置推断；体育成绩公布并录入后，直接替换为该分数。任何位次计算都使用含体育的中考计分总分。
- 合理预测同时使用成绩与年级位置，不允许只改变位次而保持预测分数不变。班型已知时参与初中历史映射；未知时按更高不确定性处理。
- 历史成绩、排名趋势与距中考剩余时间共同决定后续变化空间。越接近中考，趋势外推的权重和允许变化范围原则上越小。
- 缺少年级位置、班型或学校历史样本时，按分层先验回退并降低置信度。跨年度不直接比较原始总分。
- 学校目标以其往年录取位置百分位表示，报告呈现孩子与目标的“位置百分点差”，不伪造当年分数差或录取概率。
- 年度总分不同时，必须根据教育局公布的计分科目做科目级桥接。2026 年成绩转为 2025 年历史口径时，需处理化学、生物学、地理共 180 分的差异，禁止直接拿 640 分制成绩查询 820 分制曲线。
- 当年出分后的一分一段表属于回测数据，只在内部计算误差、偏差方向和区间覆盖率，不进入家长页面和当时的历史报告。
- 同初中同考试阶段的匿名、审核通过样本达到模型门槛时，才参与校内位置校准。
- 小程序首页不展示模型、参数、数据处理步骤或产品能力说明。
- 报告遵循“结论、理由、差距、行动、边界”顺序。可说明“近期成绩趋稳”“所在初中同位置学生历史去向”“距离中考时间有限”等家长能理解的理由，不展示公式、权重、参数、通道融合和系统处理过程。

## 报告发布

报告使用统一 HTML 模板生成，内容内联样式和图表数据，作为独立页面保存。小程序展示报告列表并用 WebView 打开；正式上线前，公开 URL 需替换为与微信登录绑定的短时签名链接。

报告至少包含：目标学校或梯队、当前分数与位置范围、合理预测分数与位置范围、与目标的差距、近次变化、可达学校梯队、主要风险、下阶段行动。预测范围超过有效宽度时，报告应诚实收敛到学校层次判断，并说明还需要哪类信息才能缩小范围。
