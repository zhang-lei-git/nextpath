# NextPath 小程序设计规范

## 设计目标

让家长在三秒内看清目标、当前处境、合理预测和下一步。界面不使用焦虑化的红色预警、夸张的数据或营销式装饰。

## 视觉令牌

| 用途 | 色值 | 说明 |
| --- | --- | --- |
| 品牌深色 | `#143F43` | 标题、重要结论、主按钮 |
| 品牌青绿 | `#16766D` | 正向状态、趋势、可交互重点 |
| 知识蓝 | `#2C6194` | 数据说明与信息层级 |
| 温和金 | `#9A6614` | 需要关注但不制造恐慌的提醒 |
| 页面底色 | `#F5F7F5` | 连续阅读时减轻视觉压力 |
| 卡片底色 | `#FFFFFF` | 信息容器 |
| 正文 | `#1C2828` | 正文，保证可读性 |
| 次要文字 | `#687574` | 时间、来源、解释 |
| 分割线 | `#E2E8E5` | 容器边界 |

字体使用系统中文字体。数字使用等宽回退字体。标题不小于 32rpx，正文 28rpx，辅助文字 24rpx；不使用随视口缩放的字号。

## 布局与组件

- 页面两侧留白 `32rpx`，卡片圆角 `16rpx`，卡片间距 `20rpx`。
- 一页只保留一个主行动：总览页为“录入最新成绩”，录入页为“确认并保存”。
- 首页结论卡按“目标、当前现状、合理预测、差距、下一步”顺序呈现。分数范围与位次范围必须成对显示。
- 完整预测可以展示具体学校梯队；基础预测只展示学校层次；暂不预测只展示需要补充的信息。页面不得自行提高后端结果粒度。
- 操作按钮高度 `96rpx`，文字按钮只用于明确命令；状态使用色彩加文字，不能只靠颜色区分。
- 页面底部导航固定为“首页、成绩、我的”，当前项以深色文字和短线标识。

## 页面规范

| 页面 | 首屏必须回答 | 主行动 |
| --- | --- | --- |
| 首页 | 孩子目前在什么层次，目标差多少 | 录入最新成绩 |
| 成绩录入 | 这次成绩是否准确 | 确认并保存 |
| 分析页 | 合理预测是什么，离目标还有多远 | 查看报告 / 更新成绩 |
| 报告列表 | 最近发生了什么变化 | 查看单次报告 / 月度报告 |

## 内容规范

- 使用“基于当前成绩”“建议关注”“仍需观察”，不用“稳上”“必进”“最后机会”。
- 小程序不展示模型名称、参数、计算步骤、数据治理过程和产品能力说明。
- 首页只保留影响家长决策的结果；数据年份、预测理由和边界放入报告，不要求家长理解算法。
- 报告中的理由使用“近期成绩变化”“所在初中同位置学生历史表现”“距离中考时间”等自然语言，不使用权重、通道、系数和模型版本等内部术语。
- 分析处理中显示明确状态并允许离开页面；失败时提供重新分析入口，不将技术错误直接展示给家长。
- 只有与孩子当前档案相关的变化才出现提醒。
