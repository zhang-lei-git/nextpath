# 2026 学校预测—实际对照与参数迭代

## 本轮状态

已生成 112 所历史数据覆盖学校的 2026 分数与位次预测，保存 `2026-school-baseline-frozen.json`。这里是“依现行模型重建的基线”，不是2026年中考前已留存的预测：2025参考数据在2026年8月才导入系统，当前参数的历史时点有效性也未能完整恢复。快照保存模型版本、参数、来源事实编号和内容哈希，之后调参不能覆盖它。

预测包含中心分数、分数区间、位次区间和批次；同名不同校区或招生方式未能完全拆开，所有行均标为诊断用途，实际值默认空。历史数据只支持西安城六区，不能代表陕西各区域。

## 可调整因素与参数

| 影响因素 | 参数/数据 | 现阶段处理 |
| --- | --- | --- |
| 历史年份远近 | `year_decay` | 已支持；本轮从按记录序号衰减修为按年度间隔衰减，避免把相隔5年当1年 |
| 招生计划变化 | `plan_elasticity` | 已支持，必须接入目标年度、同校区同招生方式计划；不能只读去年与前年的变化 |
| 计划剧变 | `max_plan_adjustment_ratio` | 新增上限，防止暴增计划把位置推到考生范围之外 |
| 校际需求、校区变化 | 招生代码/校区/批次/招生方式 | 先作为数据分组，不靠一个学校名混合拟合 |
| 试卷难度与科目改革 | 年度曲线 `target_score_shift` 等 | 暂不调；需要按分段和科目验证，不能用全局加分拟合四所学校 |
| 考生规模、普高扩招 | `candidate_count_multiplier` 和目标年人数/计划 | 当前历史人数口径矛盾，先核验；不得以截断曲线末位替代人数 |
| 录取波动 | `minimum_boundary_width_pp` | 根据独立验证覆盖率调整；不能扩大区间掩盖中心偏差 |
| 历史不足 | `preferred_observation_count` / `sparse_data_extra_width_pp` | 后台可调；1年样本不能评为充分验证 |
| 异常年与补录 | `anomaly_weight` / `anomaly_extra_width_pp` | 先记录异常原因，补录与正常批次分开比较 |

后台原先存在保存缺陷：学校边界JSON被当成学生位置参数保存。本轮修复，并新增学校参数专用表单、说明及服务端取值校验。编辑参数仍生成新版本，保留旧版本与验证记录。

## 下一轮实验验收

1. 冻结基线和截止日期，保留未通过的数据质量项，不隐瞒“事后重建”事实。
2. 独立采集实际结果，保留原文、日期、来源、招生代码、校区、批次、统招/定向/补录标记。人工审核前只在候选集对照。
3. 运行 `compare_school_outcomes.py`。只有审核通过且各维度一致、基线输入合格的记录才计入正式分数误差；实际位次与推算位次分开计分。
4. 先分解曲线误差与学校位置误差，再做参数消融和敏感性实验。参数建议必须带样本数、分段偏差和覆盖率。
5. 使用另一年度/学校组验证候选参数，审核后发布新版本。2026实际值不能写回2026考前输入或历史报告。

当前未完成：各校实际分数的原文核验、真实位次与人数核验、全校误差统计、参数最优值选择。模型尚不能据此宣称已校准准确。
