# NextPath 分析引擎需求与设计

## 目标

将孩子的成绩记录、所在初中、目标高中、已发布招录数据与政策约束，计算为可追溯的升学位置、目标边界和行动优先级。报告引擎只负责呈现分析结果，不参与判断。

家长端遵循无感原则：只输入必要信息，直接看到结论、选择与下一步。模型名称、参数、数据冲突和验证过程只出现在运营端。

## 核心定义

`位置` 是引擎的共同坐标：

- 学生位置：当前成绩和排名对应的目标地区中考位次区间。
- 学校位置：学校在对应年度、批次、计划口径下的录取位次边界和容量。
- 匹配位置：学生位置与学校位置之间的差距、波动区间和志愿风险。

分数不跨年份直接比较。跨年度、跨考试判断必须先映射到位次或标准分位。

## 可验证需求

| 编号 | 需求 | 验收标准 |
| --- | --- | --- |
| A1 | 位置计算可复现 | 每个结论记录学生数据快照、已发布数据版本、模型版本与参数版本。 |
| A2 | 数据持续补充 | 新发布的一分一段、录取线、计划、初中映射数据可在不改报告代码的情况下被新运行读取。 |
| A3 | 模型持续迭代 | 运营端可创建模型版本、调整参数、启停版本，不覆盖历史运行。 |
| A4 | 区间而非承诺 | 输出位次区间、置信等级和缺失信息；不输出“必然录取”。 |
| A5 | 学校匹配同坐标 | 目标学校先换算为录取位次边界，再与学生位置比较。 |
| A6 | 可验证 | 每个模型版本可登记回测样本数、位次误差、区间覆盖率和审核结论。 |
| A7 | 报告与页面一致 | 小程序、月度报告和 AI 问答都消费同一份结构化分析结果。 |
| A8 | 年度计分口径可追溯 | 每个年度保存计分科目、科目满分、总分、政策发布日期和官方来源；跨年度计算必须记录桥接版本。 |
| A9 | 严禁未来数据泄漏 | 预测只能读取分析日期当天已经发布的数据；当年一分一段和录取结果只进入离线回测集。 |
| A10 | 两种家长判断 | 每次分析同时保存“当前现状”和“合理预测”：前者只看最近一次成绩，后者联合预测中考分数区间与位次区间。 |
| A11 | 分数与位次一致 | 同一情景下的分数区间必须能通过同一年度位置曲线映射到输出位次区间；不得只调整位次而保持分数不变。 |
| A12 | 剩余时间影响变化空间 | 合理预测必须使用考试日期和中考日期。距中考越近，允许的自然变化范围原则上越小。 |
| A13 | 支持班型 | 学生档案可选填学校实际班型；没有学校班型字典时，统一归入创新、重点、平行、未知四类。 |
| A14 | 区间具有决策价值 | 分数与位次范围按位置分段设置最大有效宽度并经回测校准；超过阈值时降低学校判断粒度，不伪装成精确预测。 |
| A15 | 冷启动可运行 | 用户样本不足时使用已审核公开数据和保守先验运行，同时生成明确的数据缺口与采集任务；用户真实结果逐步进入校准和回测。 |

## 引擎分层

```text
已发布数据版本 + 孩子成绩快照 + 家庭约束
                    ↓
              Analysis Orchestrator
                    ↓
  Position Engine -> Target Engine -> Volunteer Optimizer -> Action Engine
                    ↓
             Structured Analysis Result
                    ↓
            小程序 / 报告 / AI 问答
```

### 1. 位置引擎

中考前先预测一组彼此一致的“中考计分总分区间 + 区域位次区间”，而不是分别给出两个互不约束的结果。证据来自年度计分方案桥接后的成绩通道，以及所在初中、班型和年级位置的历史映射通道。只有出分后，才允许直接使用当年一分一段表。

后续逐步叠加：

- 年级排名到区排名映射；
- 初中、班型和考试阶段的分层映射；
- 多次考试趋势与考试难度标准化；
- 贝叶斯层级模型或分位数回归，用于输出校准后的区间。

任何新方法必须作为新模型版本并经过回测，不能覆盖已发出的历史判断。

### 年度计分方案与分数桥接

年度计分方案是独立、版本化的政策数据，至少包含：适用年份、计分科目、每科满分、录取总分、发布日期和官方原文。当前确认的西安口径：2025 年计分 10 科、满分 820 分；2026 年计分 7 科、满分 640 分。2026 年移出录取总分的科目为化学、生物学和地理，合计 180 分。

跨年度不得直接比较原始分数，也不得只在页面上标注“总分不同”后继续计算。桥接顺序如下：

1. 先把模考学科总分与体育成绩合成为当年录取口径总分；体育未录入时固定按 60 分计算，录入后直接使用录入分数。
2. 找出两年共同计分科目、目标历史年份新增科目和移除科目。
3. 已有化学、生物学、地理成绩时直接使用；缺失部分按共同计分科目得分率估算，并记录为投影值。
4. 将桥接后的 2025 等效分数映射到 2025 历史一分一段，得到历史位置百分位。
5. 分数桥接和年级位置各自先产出位置区间与不确定性，再进入证据融合；两者不能因为都来自同一次模考而被视为完全独立。

官方依据：西安市教育局 [关于调整中考计分科目的通知](https://edu.xa.gov.cn/xwzx/tzgg/1892376145395486722.html)、[关于做好2025年初中学业水平考试工作的通知](https://edu.xa.gov.cn/xwzx/tzgg/1901069913191649282.html)、[关于做好2026年初中学业水平考试工作的通知](https://edu.xa.gov.cn/xwzx/tzgg/2028285347979890689.html)。

### 2. 目标引擎

目标高中录取参考线先通过同年度位次曲线转换为学校录取位置。学生位置与学校位置比较后输出：目标差距、边界风险、可达情景和影响最大的变量。

### 3. 志愿优化器

基于政策规则、批次、定向资格、学校位置、距离、住宿、办学偏好和风险承受度生成冲刺、稳妥、保底组合。它是约束优化问题，不由大模型直接编排。

### 4. 行动引擎

从目标位次反推需要改善的总分或关键学科区间，并优先提示可验证、影响升学边界最大的行动。后续接入知识点失分数据，但不以错题系统为前置条件。

## 模型与验证管理

每个位置模型版本包含：地区、适用年度、状态、参数、质量指标和创建时间。运营端保存参数时生成新的模型版本，旧版本自动停用而不覆盖；分析运行会同时保存当时参数快照和所用校准样本编号。参数例如：位次区间下限、曲线插值误差、年级排名权重、趋势权重。

每次验证记录绑定：模型版本、数据发布版本、验证年份、样本量、位次绝对误差、区间覆盖率、审核说明。运营端可视化展示参数和指标；家长端不展示实现细节。

回测必须严格区分训练数据和评价数据。以 2026 年为例，预测输入截止到中考前；2026 年出分后获得的一分一段表只能用于计算误差、分段偏差和区间覆盖率，不能回填或改写已经生成的 2026 年预测。网传待核验表必须带数据质量警告，不能作为正式模型真值。

初期由运营人员录入回测指标。后续建设历史样本数据集和自动回测任务，自动生成验证记录。

### 分数与位次联合预测

每一次中考前分析都按以下顺序运行：

1. **输入标准化**：统一考试日期、考试阶段、计分科目、满分、体育、年级排名与人数。班型优先匹配学校自己的班型字典，无法匹配时归入创新、重点、平行或未知。
2. **当前能力估计**：成绩通道将最近成绩桥接到中考计分口径；位置通道把 `年级排名 / 年级人数` 与初中、班型、考试阶段的历史中考结果映射到区域百分位。班级排名仅在班型、班级人数和分班规则已知时作为辅助证据。
3. **考试难度校正**：根据同校、同班型、同阶段的“模考成绩/排名—最终中考成绩/位次”配对样本估计，允许学校和班型共享上层先验。样本不足时只扩大不确定性，禁止写死“加 10 分”或“乘 1.1”。
4. **后续发展预测**：同时考虑最近 3 至 5 次成绩趋势、排名趋势、波动程度、科目结构、考试阶段以及距中考剩余天数。趋势不是线性外推；剩余时间用于约束可变化空间，临近中考时预测中心和区间都应更稳定。
5. **联合生成**：模型输出中考总分与区域百分位的联合分布，再通过预测年度的分数—位次曲线进行一致性约束，形成一组互相匹配的分数区间和位次区间。
6. **目标匹配**：用位次区间与高中历年录取位置分布比较，输出学校层次、目标差距和冲刺/稳妥/保底边界。学校判断不得绕过联合预测结果单独使用某一个通道。

模型输出同时保存两个通道的原始估计、联合分布摘要、配对样本数、剩余天数、班型匹配层级、难度档案、冲突大小和一致性校验结果；这些字段仅供运营审核、回测和版本比较。家长端只消费最终结论、范围和下一步，分析报告可呈现家长能理解的预测理由。

理论上，这是对学生最终中考表现的联合条件分布 `P(中考分数, 区域位次 | 初中, 班型, 当前成绩, 当前排名, 历史变化, 剩余时间)` 进行估计。冷启动阶段采用可审计的分段映射、保守先验和一致性校准；积累足够跨届配对样本后，在相同输入输出契约下替换为分位数回归或贝叶斯层级模型，并按学校、班型和考试阶段做部分汇聚。

### 区间宽度与可用性

区间不是固定加减分，也不能为了看起来准确而任意缩窄。模型版本按位次区段和距中考时间配置“最大有效宽度”，并通过历史回测确定：

- 分数区间覆盖真实中考分数的比例达到设定目标；
- 位次区间覆盖真实中考位次的比例达到设定目标；
- 在覆盖率达标前提下，平均区间宽度应持续缩小；
- 输出分数区间映射出的位次范围必须与输出位次区间相交，并通过一致性阈值；
- 超过最大有效宽度时，只输出较宽的学校层次或梯队，不输出精确到某一所学校的结论，并向数据平台提交缺口任务。

最大有效宽度不是全地区统一常数。头部、腰部和尾部的分数—位次密度不同，必须分段校准；距中考 3 个月和 3 天也使用不同的变化上限与区间参数。

### 家长端的两种判断

家长端必须固定按“目标、当前现状、合理预测”顺序展示，不混用两个口径：

1. **当前现状**：只根据最近一次模考的学科成绩加体育分，换算到历史位置；不使用历次走势、年级排名或任何学校难度档案。
2. **合理预测**：以当前成绩和年级位置为共同起点，结合初中、班型、历次成绩与排名变化、考试难度、波动程度和距中考时间，联合形成彼此匹配的中考计分总分区间和区域位次区间。

两种判断的总分均为含体育的中考计分总分。体育未录入时固定为 60 分；成绩公布后，录入分数直接替代 60 分。合理预测所使用的趋势权重、时间衰减、变化上限和区间宽度均为模型版本参数，且学校/班型难度只能来自审核样本达标的档案。

## 实施状态与下一阶段

当前基线已经具备模型版本、参数与验证记录、历史曲线插值、分析运行快照和报告快照，但尚未满足本次确定的联合预测要求。下一阶段按以下顺序实施：

1. 扩展学生档案、学校字典和校准样本，加入班型、考试日期、最终中考分数等字段。
2. 建立距中考时间、成绩/排名趋势和波动特征，替换当前简单趋势调整。
3. 让成绩通道与位置通道共同生成分数—位次联合结果，增加一致性校验，删除“分数不变、位次单独变化”的路径。
4. 增加分段区间宽度、覆盖率、平均宽度和分数—位次一致性回测指标。
5. 建立 `DataGap` 与运营待办，使宽区间和缺失学校/班型数据能触发定向补数。
6. 更新首页和 HTML 报告消费契约；志愿优化在联合预测稳定后接入。

## 初中位置校准设计

校准样本保存去标识化的纵向配对数据：地区、初中、班型标准类与学校原始班型、考试阶段和日期、模考科目/总分/满分、年级排名与人数、最终中考总分、最终区域排名及区域考生人数，不保存学生姓名、联系方式或试卷。只有“模考输入—最终中考结果”成对存在的数据，才能用于学习难度和发展变化；仅有聚合排名的数据只能用于位置先验。运营人员先提交样本，再审核通过；未审核和被拒绝样本绝不参与家长端计算。

计算时优先匹配同初中、同班型、同考试阶段样本；不足时依次回退到同初中同阶段、同层次初中同阶段、地区同阶段的上层先验，每次回退都扩大区间。只有分层回测证明误差下降且覆盖率达标，才允许缩小区间。

## 冷启动与数据飞轮

产品推广初期不能等待用户数据积累完成后才提供结果。系统按以下顺序启动：

1. 主动采集教育局、考试院、学校官网和官方公众号的政策、计分方案、招生计划、录取结果和学校班型信息。
2. 对可信公开渠道中的初中层次、班型、模考难度、排名去向等信息登记为候选事实；交叉验证、人工审核后才能进入先验或报告依据。
3. 对缺少学校映射的用户分析，自动生成按“地区—初中—班型—考试阶段”聚合的数据缺口任务，指导运营优先补最影响当前用户判断的数据。
4. 用户后续自愿提供实际中考结果时，形成去标识化纵向配对样本；达到门槛后进入训练候选集，经回测和审核发布为新模型版本。
5. 任何公开信息和用户数据都不能直接在线改动预测参数，必须经过治理、验证、审批和版本发布。

## 边界

- 大模型只能用于资料提取、异常提示、解释和报告写作，不直接输出位次或录取结论。
- 数据不足时引擎必须扩大区间、降低结论粒度并向数据平台提交缺口任务，不伪造精确结果。
- 家长端不使用“模型说明”“算法步骤”等功能介绍文案；结论本身必须可理解。
