# NextPath 分析引擎需求与设计

## 目标

将孩子的成绩记录、所在初中、目标高中、已发布招录数据与政策约束，计算为可追溯的升学位置、目标边界和行动优先级。报告引擎只负责呈现分析结果，不参与判断。

家长端遵循无感原则：只输入必要信息，直接看到结论、选择与下一步。模型名称、参数、数据冲突和验证过程只出现在运营端。

## 核心定义

`位置` 是引擎的共同坐标：

- 学生位置：当前成绩和排名对应的目标地区中考位次区间。
- 学校位置：学校在对应年度、批次、计划口径下的录取位次边界和容量。
- 匹配位置：学生位置与学校位置之间的差距、波动区间和志愿风险。

分数不跨年份直接比较。跨年度、跨考试判断必须先映射到位次或标准分位。

## 可验证需求

| 编号 | 需求 | 验收标准 |
| --- | --- | --- |
| A1 | 位置计算可复现 | 每个结论记录学生数据快照、已发布数据版本、模型版本与参数版本。 |
| A2 | 数据持续补充 | 新发布的一分一段、录取线、计划、初中映射数据可在不改报告代码的情况下被新运行读取。 |
| A3 | 模型持续迭代 | 运营端可创建模型版本、调整参数、启停版本，不覆盖历史运行。 |

## 引擎分层

```text
已发布数据版本 + 孩子成绩快照 + 家庭约束
                    ↓
              Analysis Orchestrator
                    ↓
  Position Engine -> Target Engine -> Volunteer Optimizer -> Action Engine
                    ↓
             Structured Analysis Result
                    ↓
            小程序 / 报告 / AI 问答
```

### 1. 位置引擎

中考前的位置计算由两条独立证据共同完成：年度计分方案桥接后的历史成绩曲线，以及所在初中的年级位置映射。只有出分后，才允许直接使用当年一分一段表。

后续逐步叠加：

- 年级排名到区排名映射；
- 初中历史样本的分层映射；
- 多次考试趋势与考试难度标准化；
- 贝叶斯层级模型或分位数回归，用于输出校准后的区间。

任何新方法必须作为新模型版本并经过回测，不能覆盖已发出的历史判断。

### 年度计分方案与分数桥接

年度计分方案是独立、版本化的政策数据，至少包含：适用年份、计分科目、每科满分、录取总分、发布日期和官方原文。当前确认的西安口径：2025 年计分 10 科、满分 820 分；2026 年计分 7 科、满分 640 分。2026 年移出录取总分的科目为化学、生物学和地理，合计 180 分。

跨年度不得直接比较原始分数，也不得只在页面上标注“总分不同”后继续计算。桥接顺序如下：

1. 先把模考学科总分与体育成绩合成为当年录取口径总分；体育未录入时固定按 60 分计算，录入后直接使用录入分数。
2. 找出两年共同计分科目、目标历史年份新增科目和移除科目。
3. 已有化学、生物学、地理成绩时直接使用；缺失部分按共同计分科目得分率估算，并记录为投影值。
4. 将桥接后的 2025 等效分数映射到 2025 历史一分一段，得到历史位置百分位。
5. 分数桥接和年级位置各自先产出位置区间与不确定性，再进入证据融合；两者不能因为都来自同一次模考而被视为完全独立。

官方依据：西安市教育局 [关于调整中考计分科目的通知](https://edu.xa.gov.cn/xwzx/tzgg/1892376145395486722.html)、[关于做好2025年初中学业水平考试工作的通知](https://edu.xa.gov.cn/xwzx/tzgg/1901069913191649282.html)、[关于做好2026年初中学业水平考试工作的通知](https://edu.xa.gov.cn/xwzx/tzgg/2028285347979890689.html)。

### 2. 目标引擎

目标高中录取参考线先通过同年度位次曲线转换为学校录取位置。学生位置与学校位置比较后输出：目标差距、边界风险、可达情景和影响最大的变量。

### 3. 志愿优化器

基于政策规则、批次、定向资格、学校位置、距离、住宿、办学偏好和风险承受度生成冲刺、稳妥、保底组合。它是约束优化问题，不由大模型直接编排。

### 4. 行动引擎

从目标位次反推需要改善的总分或关键学科区间，并优先提示可验证、影响升学边界最大的行动。后续接入知识点失分数据，但不以错题系统为前置条件。

## 模型与验证管理

每个位置模型版本包含：地区、适用年度、状态、参数、质量指标和创建时间。运营端保存参数时生成新的模型版本，旧版本自动停用而不覆盖；分析运行会同时保存当时参数快照和所用校准样本编号。参数例如：位次区间下限、曲线插值误差、年级排名权重、趋势权重。

每次验证记录绑定：模型版本、数据发布版本、验证年份、样本量、位次绝对误差、区间覆盖率、审核说明。运营端可视化展示参数和指标；家长端不展示实现细节。

回测必须严格区分训练数据和评价数据。以 2026 年为例，预测输入截止到中考前；2026 年出分后获得的一分一段表只能用于计算误差、分段偏差和区间覆盖率，不能回填或改写已经生成的 2026 年预测。网传待核验表必须带数据质量警告，不能作为正式模型真值。

初期由运营人员录入回测指标。后续建设历史样本数据集和自动回测任务，自动生成验证记录。

### 双通道位置估计（本阶段实现）

每一次中考前分析都按以下顺序运行：

1. **得分通道**：将模考成绩按当年计分方案补足体育分数，桥接至最近可用的历史年度，再映射为历史考生百分位。体育未录入时按 60 分，录入后按实际录入分数。
2. **年级位置通道**：先用 `年级排名 / 年级人数` 形成保守先验；同初中、同考试阶段的审核样本达到门槛后，用历史映射替代先验中心。
3. **难度校正**：默认只增加不同考试阶段带来的不确定性。只有学校、考试阶段、样本数、残差和审核状态齐全的难度档案，才允许改变得分通道的中心位置。禁止写死“某校加 10 分”或“乘 1.1”。
4. **证据融合**：按各通道不确定性的倒数加权，并用相关性放大系数避免虚假的精度提升。两通道差异超过冲突阈值时，结果必须覆盖两边范围、标为低置信度，等待后续考试或校准样本验证。

模型输出同时保存两个通道的区间、样本数、难度档案是否生效、融合权重和冲突大小；这些字段仅供运营审核、回测和版本比较，家长端只消费最终的结论、范围和下一步。

理论上，这相当于将不可直接比较的原始分数和校内名次转换到共同的“区域考生百分位”潜变量后进行带相关误差的测量融合。当前采用可审计的分段插值与逆方差融合；当积累到足够跨届样本后，可在相同输入输出契约下替换为分位数回归或贝叶斯层级模型，按学校和考试阶段做部分汇聚。

### 家长端的两种判断

家长端必须固定按“目标、当前现状、合理预测”顺序展示，不混用两个口径：

1. **当前现状**：只根据最近一次模考的学科成绩加体育分，换算到历史位置；不使用历次走势、年级排名或任何学校难度档案。
2. **合理预测**：以当前成绩为起点，结合历次成绩得分率变化和审核通过的学校考试难度档案，先形成预测中考计分总分区间，再由这套分数换算对应位置。年级位置只作为内部校验信号，不单独改变家长端的预测位置。

两种判断的总分均为含体育的中考计分总分。体育未录入时固定为 60 分；成绩公布后，录入分数直接替代 60 分。合理预测所使用的趋势权重、单次最大调整和区间宽度均为模型版本参数，且学校难度只能来自审核样本达标的档案。

## 第一开发阶段

1. 实现位置模型版本、参数和验证记录的持久化与运营 API。
2. 将当前一分一段插值封装为 `PositionEngine`，由激活模型参数控制区间。
3. 在目标分析中同时计算学生位次和学校录取位次。
4. 运营台增加模型列表、参数编辑、验证记录查看与新增验证记录。
5. 保存分析运行快照；志愿优化作为下一阶段。

## 初中位置校准（第二阶段已实现）

校准样本仅保存去标识化的聚合位置：地区、初中、考试阶段、届别、当时年级排名、年级人数、最终中考区域排名以及该届区域考生人数，不保存学生姓名、联系方式或试卷。区域考生人数用于将跨届区域排名标准化为百分位；旧样本缺失时只能使用历史参考年度人数并提高不确定性。运营人员先提交样本，再审核通过；未审核和被拒绝样本绝不参与家长端计算。

计算时必须同时满足以下条件：孩子已录入年级排名与年级人数、考试名称可识别为同一考试阶段、同一初中同阶段的审核通过样本达到模型设置的最少数量。满足后，模型把校内百分位映射为区域位次，并以保守权重与一分一段曲线结果融合；任一条件不满足即回退到公开曲线。校准只改变位置中心，不缩小默认不确定区间，直到回测证明确有改善。

## 边界

- 大模型只能用于资料提取、异常提示、解释和报告写作，不直接输出位次或录取结论。
- 数据不足时引擎必须降低置信度或提示需要补录的数据，不伪造精确结果。
- 家长端不使用“模型说明”“算法步骤”等功能介绍文案；结论本身必须可理解。
