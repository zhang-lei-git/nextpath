# NextPath 非功能与隐私要求

## 目标

保证小程序、分析引擎、报告和数据平台可以从内部测试平稳扩展到公众使用。指标按环境和版本记录，不能以“后续优化”替代验收。

## 性能与容量

| 编号 | 要求 | 首期验收标准 |
| --- | --- | --- |
| N1 | 常用读取性能 | 在 200 个并发用户下，首页、成绩列表和报告列表 API 的 P95 响应时间不超过 500ms。 |
| N2 | 成绩保存性能 | 成绩确认接口 P95 不超过 1s，只负责可靠保存并创建幂等分析任务。 |
| N3 | 分析报告时效 | 95% 的单次分析与 HTML 报告在 30s 内完成；超时任务可重试且页面显示状态。 |
| N4 | 水平扩展 | API 无会话状态，分析、报告、OCR 和采集 worker 可独立增加实例；文件不写入单机临时目录作为唯一副本。 |
| N5 | 容量验证 | 每次公开发布前执行固定数据集压测，记录吞吐、P95/P99、错误率、数据库连接数和队列积压。 |

达到 10 万注册用户或峰值并发接近当前容量 60% 时，必须重新压测并调整实例、数据库、缓存和队列容量，不等待故障发生后扩容。

## 可靠性与一致性

- 公开服务月可用性目标为 99.9%，计划维护单独公告。
- 成绩保存、分析运行和报告生成使用稳定幂等键；客户端重试不得产生重复成绩或重复报告。
- 分析输入快照、模型版本、数据版本和报告必须绑定同一 `run_id`，报告只能在全部结果持久化后发布。
- worker 任务失败自动重试，超过阈值进入人工处理队列；不得静默丢失。
- 模型或数据版本发布失败时保持旧版本继续服务；支持一键回滚到上一已验证版本。
- 第三方 OCR、大模型或采集服务不可用时，人工录入、基础分析和历史报告仍可使用。

## 安全与权限

- 全部外部访问使用 HTTPS；密码采用强哈希存储，密钥只从密钥管理或运行环境读取，不进入代码和前端。
- 家长只能访问自己授权的学生档案、成绩和报告；运营账号按采集、治理、审核、发布和管理员分权。
- 数据发布、模型启停、用户管理、授权变更、数据导出和删除均记录审计日志。
- 上传文件限制类型、大小和数量，执行恶意文件检测；原文件存储使用不可执行权限和随机对象键。
- API 具备登录限流、接口限流、防重放和异常访问告警；管理接口不得与家长接口共用公开权限。

## 隐私与未成年人保护

- 首次保存学生成绩前取得监护人服务授权；模型训练、营销触达和第三方共享分别授权，不捆绑同意。
- 用户可以查看、导出、更正和删除孩子的数据，也可以单独撤回训练授权。
- 原始截图和语音完成识别并经家长确认后按最短期限删除；默认不用于训练。
- 分析训练集使用去标识化 ID，并隔离姓名、手机号、微信标识和原始文件。
- 删除请求在 30 天内完成在线删除或不可逆匿名化，并保留处理审计记录。

## 备份与恢复

- PostgreSQL 每日全量备份并持续保存增量日志；对象存储开启版本保护。
- 首期恢复点目标 `RPO <= 24h`，恢复时间目标 `RTO <= 4h`；公众付费后提升为 `RPO <= 1h`、`RTO <= 2h`。
- 每季度执行一次恢复演练，验证学生档案、成绩、分析快照、报告、发布数据和授权记录可恢复。

## 监控与发布

- 监控 API 错误率和延迟、队列积压、任务失败率、数据库资源、报告生成耗时、模型版本分布和数据缺口数量。
- 预测质量监控按初中、班型、考试阶段、距中考时间和位置区段分组；发现误差或区间覆盖持续恶化时停止新模型并回滚。
- 代码、数据库迁移、数据版本和模型版本分别发布，任何一次发布都必须可追踪、可回滚。
- 正式发布前完成自动测试、数据边界测试、权限测试、关键页面真机测试和压测；测试数据不得出现在生产预测或家长报告中。
