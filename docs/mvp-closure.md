# 首个闭环验收标准

## 用户流程

1. 家长首次进入，仅填写孩子称呼、所在初中、年级；目标高中选填。
2. 家长录入周考、月考或模考的各科成绩、班级排名、年级排名；班型选填，系统自动汇总总分。
3. 家长在首页先看到当前现状和中考预估对应的学校范围；已设置目标高中时，再看到目标差距。在报告页查看同一结果的趋势、学校梯队、预测理由和下一步。

## 验收条件

- 缺少成绩、满分、考试日期或目标年度计分方案时不得展示升学结论，只引导补全关键资料。
- 成绩口径齐全但缺少排名、班型或学校历史样本时，只展示基础预测和学校层次，不展示精确学校判断。
- 成绩记录保存后，首页和报告使用同一次最新成绩，且显示相同的当前层次和数据年份。
- 报告必须说明估算依据和缺失的数据；不得使用“稳上”“保证录取”等承诺性措辞。
- 目标高中存在公开参考数据时显示参考差距；不存在时明确提示无可用参考数据。
- 图像、语音识别均只能产出待确认候选，最终成绩以家长确认保存为准。
- 当前现状和合理预测都必须同时给出一致的分数范围与位次范围；不能出现分数不变而位次单独变化。
- 未设置目标高中时，首页仍须展示当前现状和中考预估各自对应的学校层次；只有完整预测才可列出具体学校。设置目标高中是比较差距的后续操作，不是查看升学范围的前置条件。
- 首页不解释算法和产品能力；报告只解释家长能理解的预测理由，不展示模型过程和参数。
- 连续录入 7 次成绩必须生成至少 7 份单次报告，但产品不得限制继续录入；同一自然月最多自动生成一份月度报告。

## 当前数据边界

西安城六区为首期样板。中考前只能使用分析日期之前已发布的历年政策、计分方案、录取位置与初中映射数据；2026 年出分后数据只能用于回测，不能倒灌到此前预测。冷启动期优先通过公开信息补齐政策、学校、班型和历史招录基础数据，用户实际模考—中考配对结果经授权、治理和验证后再提升模型。正式开放前需完成官方数据复核、扩充学校与初中班型库、接入 OCR/ASR 与微信身份认证。
